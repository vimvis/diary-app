# 오늘의 기억

날짜별로 세 가지 기억을 기록하고, 과거 같은 날짜의 기록을 돌아보는 정적 웹 앱입니다.

## 실행과 검증

별도의 빌드 과정 없이 정적 웹 서버에서 `index.html`을 제공합니다.

```sh
python3 -m http.server 8000
node --test tests/app.test.cjs
```

## 임시 저장과 백업

- 입력할 때마다 해당 날짜의 초안을 현재 브라우저의 localStorage에 저장합니다.
- 날짜 이동이나 새로고침 후 초안이 있으면 서버 기록보다 먼저 복원합니다.
- ‘일기 저장하기’를 눌러야 Firestore에 반영됩니다. 성공한 날짜의 초안만 제거합니다.
- ‘백업 다운로드’는 서버의 전체 일기와 현재 브라우저의 초안을 JSON 파일로 내보냅니다.
- 백업 파일의 `entries`는 저장된 기록, `drafts`는 아직 반영하지 않은 초안입니다.
- ‘기록 관리’에서 JSON 백업을 가져올 수 있습니다. 가져온 기록은 로컬 초안으로 보관하며 기존 초안은 건너뜁니다. 날짜별로 확인하고 저장 버튼을 눌러 서버에 반영하세요.
- 잘못된 형식·날짜가 포함된 백업은 거부하고, 저장 공간이 부족하면 이번 가져오기를 취소합니다. 파일은 최대 10MB입니다.
- 브라우저 데이터 삭제나 시크릿 모드 종료 시 초안을 잃을 수 있으므로 중요한 기록은 저장하고 백업하세요.

## 데이터와 접근 권한

Firebase Firestore의 `entries/YYYY-MM-DD` 구조를 사용합니다. 이 저장소에는 Firebase 보안 규칙이 포함되어 있지 않으며 사용자별 인증도 구현되어 있지 않습니다. 접근 권한은 Firebase 콘솔에서 별도로 관리해야 합니다.

과거 회고는 최초 기록 한 건으로 시작 연도를 찾은 뒤 연도별 같은 날짜의 문서만 조회합니다. 일반 조회에서는 전체 기록을 내려받지 않습니다. 전체 조회는 사용자가 백업을 누를 때 수행합니다.

## 편의 기능

- 날짜 좌우 버튼으로 하루씩 이동하고 ‘오늘로’ 또는 하단 ‘오늘’으로 복귀합니다.
- 작성한 기억 수와 글자 수를 표시합니다. 변경이 있으면 저장 버튼이 활성화됩니다.
- `⌘ + Enter` 또는 `Ctrl + Enter`로 저장합니다. 모바일에서는 저장 버튼을 화면 아래에 고정합니다.
- ‘임시 저장 취소’는 마지막 서버 저장 내용을 복원합니다. 서버의 일기는 삭제하지 않습니다.
- 불러오기 실패 시 ‘다시 불러오기’ 버튼을 제공합니다.
